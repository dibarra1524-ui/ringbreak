# Ringbreak physics ideas

The weekly lab run takes the top unchecked idea, builds it as a new recipe option, tests it, and ticks it off.
Every lab run also adds two fresh ideas at the bottom, so this list never runs out. The daily formula gives
brand-new options extra airtime (novelty bonus) and retires options that keep scoring clearly below average.

## Built

- [x] Central pull (the original)
- [x] Vortex: balls swirl around the centre
- [x] Gravity: balls fall down the screen and pile up
- [x] Tumble: gravity turns a full circle once per loop
- [x] Pulse: the pull breathes in and out four times per loop
- [x] Pegs: bumpers that light up in the ball's colour and tick when hit (arc and field layouts)
- [x] Bounce: bouncy and soft balls
- [x] Suck-in before each slam (keeps every physics type building to a big finale)

## Next up

- [ ] Magnet jaws: the jaws attract balls only while they are open, then slam
- [ ] Orbiting bumper: one large bumper circles the arena once per loop
- [ ] Split walls: the outline is made of two halves that wobble apart and back
- [ ] Wind gusts: short sideways gusts that alternate direction on every pinch
- [ ] Chain colours: a ball that touches a different colour takes it over, so colour spreads like a wave
- [ ] Heavy first ball: the first ball is big and heavy and shoves the others around until the finale
- [ ] Spinning paddle: a long bar in the arena that turns slowly and bats balls around
- [ ] Shrinking arena: the outline breathes smaller and bigger in time with the pinches
- [ ] Popcorn: balls that touch the wall get a small random kick
- [ ] Twin machines: two smaller jaw sets at opposite sides of the arena
- [ ] Slow motion slam: time slows to 30% for half a second at the last pinch
- [ ] Sticky clusters: balls of the same colour stick together briefly when they touch
